# Tic Tac Toe Game 🎮

A simple console-based Tic Tac Toe game developed using the C programming language.  
This game supports two players and includes automatic win and draw detection.

---

## 📌 How It Works
- The game board contains numbers from 1 to 9.
- Players take turns entering a position number.
- The selected position is marked with **X** or **O**.
- The game checks for a winner after every move.
- If all positions are filled without a winner, the game ends in a draw.

---

## ✨ Features
- Two-player gameplay
- Dynamic board display
- Win detection (rows, columns, diagonals)
- Draw detection
- Input validation

- C Language
